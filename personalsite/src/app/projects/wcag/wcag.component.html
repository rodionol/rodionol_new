WCAG => set of Accessibility recommendations to make a website usable for people with disabilities Version 2.0 => required version to adhere to in most jurisdictions Version 2.1 => latest version, usually not required to adhere to it recommendations to make content on the web accessible to people with low vision blindness deafness hearing loss learning disabilities cognitive limitations limited movement speech impediments photosensitivity combinations of above written as testable content non-tech specific W3C recommends adhering to Version 2.0 or 2.1 WCAG is created by the Accessibility Guidelines Working Group (AGWG)

There are four principles of Accessibility

  1. 1 Percievable
  2. 2 Operable
  3. 3 Understandable
  4. 4 Robust

There are 12 Guidelines & there are 12 testable success criteria (one for each guideline)

  • 1.1 Text alternatives
  • 1.2 alternatives for time based media
  • 1.3 adaptable content (content can be presented in diff ways)
  • 1.4 distinguishable (make it easy for all users to see content)
  • 2.1 Keyboard accessible
  • 2.2 enough time to be provided to user to see and use content
  • 2.3 do not design in a way that causes seizures
  • 2.4 navigable
  • 3.1 readable
  • 3.2 predictable
  • 3.3 input assistance
  • 4.1 compatible
